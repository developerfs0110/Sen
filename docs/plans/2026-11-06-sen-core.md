**Goal:** Xây plugin Antigravity `sen-method`: rule phân cấp luôn bật, 7 skill `sen-*`, script cài đặt/cập nhật, mẫu workspace, README hai ngôn ngữ, hướng dẫn cho người mới. Sau đó cài vào workspace `d:\TUNBH\Workspace`.

**Architecture:** Repo là một plugin Antigravity: `plugin.json`, `rules/AGENTS.md`, `skills/sen-*/SKILL.md`. Mọi logic xác định được (liệt kê ổ đĩa, tạo thư mục, phát hiện công cụ, file khóa phiên bản, kiểm tra cập nhật) nằm trong một module PowerShell `scripts/Sen.psm1` có test. **Tech Stack:** Markdown (rule/skill/tài liệu), PowerShell 5.1+ (Windows, chính), Bash (macOS/Linux, ngang tính năng ở mức cơ bản), Git, `winget`/`brew`, Windows Task Scheduler / cron.
