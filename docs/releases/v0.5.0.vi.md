## 4. Cải tiến & Tính năng mới (Improved & Added)
- EPIC 01 & 02 — Động cơ Truy vết Yêu cầu 7 mắt xích (Register-SenRequirement, Get-SenRequirementTraceability): Quản lý vòng đời yêu cầu (REQ -> DESIGN -> TASK -> CODE -> TEST -> EVIDENCE -> ACCEPTANCE), tự động khử trùng lặp, phát hiện xung đột (conflictWith), gắn cờ NEEDS_CLARIFICATION, và tích hợp trực tiếp vào Test-SenDeliveryGate. / Full 7-link Requirement Traceability Matrix (RTM) integrated into the delivery gate.
- EPIC 03 — Động cơ Bằng chứng & Phát hiện Bằng chứng Cũ (Register-SenEvidence, Test-SenEvidenceValidity): Lưu trữ bằng chứng kiểm thử/build có đóng dấu thời gian và tự động chuyển sang trạng thái STALE (erified = False) ngay khi file mã nguồn liên quan bị sửa đổi sau thời điểm tạo bằng chứng. / Timestamped verification evidence with automatic file-mtime stale invalidation.
- EPIC 04 & 06 — Máy trạng thái Công việc & Phân tích Tác động Thay đổi (Invoke-SenTaskTransition, Invoke-SenChangeImpactAnalysis): Kiểm soát chuyển đổi trạng thái hợp lệ kèm nhật ký bất biến (history), thời hạn khóa (lockExpiresAt), và tự động lan truyền trạng thái stale cho toàn bộ công việc/bằng chứng phụ thuộc phía sau khi một yêu cầu hoặc task bị mở lại. / Formal task state machine with immutable audit history and transitive DAG change impact invalidation.
- EPIC 05 — Phục hồi Sau Sự cố & Phát hiện File Chưa Commit (Invoke-SenCheckpointResume): Kết hợp trạng thái DAG với git status --porcelain, thu hồi các khóa hết hạn (ExpiredLocks), vô hiệu hóa bằng chứng của các file đang sửa dở, và xuất danh sách PreventDuplicateIds chống chạy lặp. / Crash recovery combining DAG state with uncommitted git working tree inspection.
- EPIC 07 & P1 — Chống Sửa Xóa Test (Test-SenSuiteIntegrity) & Tự động Nâng Cấp Độ Giữa Chừng (Test-SenMidTaskEscalation): Ngăn chặn hành vi xóa Assert- để vượt qua CI và tự động nâng từ Cấp 1 lên Cấp 2/3 khi phạm vi sửa đổi vượt ngưỡng (>= 3 files hoặc chạm vào Auth/Database/Payment). / Anti-test-tampering assertion guard and automatic mid-task tier escalation.
- Grok & Claude P1/P2 — Chế độ Cấp 2 Nhanh (ExpressMode, ComplexityLevel C0–C4), Ước lượng Token chuẩn tiếng Việt (Measure-SenTokenEstimate), Chế độ core/ull (Set-SenEdition), Vòng đời Bài học Kinh nghiệm có độ tin cậy/hết hạn (Add-SenExecutionLesson), và Bảng Phân loại Mức độ Hỗ trợ từng IDE (CapabilityLevel: ull-hook, ule+skill, ule-only). / Tier 2 Express Mode, UTF-8 Vietnamese token estimator, Core/Full edition switch, lesson TTL/confidence, and per-harness capability matrix.
