# Release Notes `v0.5.0` (English) - Sen (`sen-method`)

- **Version:** `v0.5.0`
- **Release Date:** 2026-11-08
- **Vietnamese Edition:** [v0.5.0.vi.md](v0.5.0.vi.md) | **Master Index:** [RELEASE-NOTES.en.md](RELEASE-NOTES.en.md)

## 1. Summary
**Sen `v0.5.0`** unifies 39 engineering improvements synthesized from 3 independent evaluations (**Grok**, **ChatGPT v1/v2**, **Claude**): 7-Link Requirement Traceability Matrix (`RTM Engine`), Evidence Validity & Automatic Stale Detection (`Evidence Engine`), Formal Task State Machine, Transitive DAG Change Impact Analysis, Canonical Symlink & Sensitive Host Path Guard, 2D `Complexity × Risk` Matrix (`Tier 2 Express Mode`), and the **Mandatory Bilingual Release Notes Gate**.

## 2. Fixed
- **P0 Security (`Test-SenSafeWorkspacePath`, `guard.ps1`, `guard.sh`, `hooks.json`):** Added `read_file` to the `PreToolUse` matcher; blocked reading/writing sensitive host credential paths (`~/.ssh`, `~/.aws`, `~/.gnupg`, `~/.kube`, `id_rsa`, `.aws/credentials`), blocked workspace escape via Symlink/Junction (`ReparsePoint`), and blocked dangerous remote shell pipe commands (`curl | sh`, `wget | bash`, `cat ~/.ssh/id_rsa`).
- **P0 Multi-Project Subfolder Discovery (`Resolve-SenWorkspaceRoot`):** Fixed `.agents/` discovery when opening or running commands directly inside a nested child project folder (e.g., `Code/OmniHub`).
- **P0 Atomic Concurrent Task Persistence (`Save-SenTasks`):** Wrapped `.agents/office/tasks.json` Read-Modify-Write operations in a cross-process `Named Mutex` (`Local\SenTasksMutex_*`) with concurrent new-task merging to prevent race conditions across parallel subagents.
- **P0 Legal Gate Tri-State (`Invoke-SenVnLawScan`):** Fixed over-permissive static scan pass assumptions by upgrading to a strict tri-state verdict (`Verdict = PASS / FAIL / UNKNOWN`) with `LawCatalogVersion = "2026.11"`, `EffectiveDate`, and `LegalDisclaimer`.
- **P1 Cross-Platform Schedule & Uninstaller (`register-schedule.sh`, `uninstall.ps1`, `uninstall.sh`, `Uninstall-SenSelf`):** Added POSIX `crontab` scheduler registration on macOS/Linux and clean cross-platform uninstallers that remove scheduled tasks/cron entries without leaving orphan jobs.

## 3. Removed
- Removed unconditional `Verdict = PASS` behavior in `Invoke-SenVnLawScan` when form/data signals require runtime or policy verification (now reports `UNKNOWN`).
- Removed unguarded concurrent overwrites on `.agents/office/tasks.json` across parallel processes.
- Removed uniform hook capability assumptions across all 6 harnesses; replaced with explicit per-harness `CapabilityLevel` (`full`, `rules-and-skills`, `rules-only`) in `Get-SenSupportedHarnesses`.

## 4. Improved & Added
- **EPIC 01 & 02 — 7-Link Requirement Traceability Matrix (`Register-SenRequirement`, `Get-SenRequirementTraceability`):** Full requirement lifecycle tracking (`REQ -> DESIGN -> TASK -> CODE -> TEST -> EVIDENCE -> ACCEPTANCE`), automatic deduplication, conflict detection (`conflictWith`), `NEEDS_CLARIFICATION` flagging, `PROJECT ACCEPTANCE REPORT` generation, and direct enforcement in `Test-SenDeliveryGate`.
- **EPIC 03 — Evidence Engine & Stale Detection (`Register-SenEvidence`, `Test-SenEvidenceValidity`):** Timestamped test/build verification evidence that automatically transitions to `STALE` (`verified = $false`) whenever any linked source file is modified after the evidence timestamp.
- **EPIC 04 & 06 — Formal Task State Machine & DAG Change Impact Analysis (`Invoke-SenTaskTransition`, `Invoke-SenChangeImpactAnalysis`):** Enforces valid state transitions with an immutable `history[]` audit trail and `lockExpiresAt` lease TTL, and automatically propagates `stale` (`needsReverification`) across downstream dependent tasks and evidence when an upstream requirement or task changes.
- **EPIC 05 — Git-Aware Crash/Restart Recovery (`Invoke-SenCheckpointResume`):** Combines DAG recovery state with `git status --porcelain` inspection (`UncommittedFiles`), releases expired task locks (`ExpiredLocks`), invalidates evidence for uncommitted modified files, and outputs `PreventDuplicateIds`.
- **EPIC 07 & Claude P1 — Anti-Test-Tampering Guard (`Test-SenSuiteIntegrity`) & Mid-Task Tier Escalation (`Test-SenMidTaskEscalation`):** Prevents deleting `Assert-` statements in `tests/` to fake green CI runs, and automatically escalates Tier 1 workflows to Tier 2/3 when modified file count (`>= 3` files) or critical paths (`Auth`/`Database`/`Payment`) exceed Tier 1 boundaries.
- **Grok & ChatGPT 2D Matrix — Tier 2 Express Mode (`ExpressMode`, `ComplexityLevel C0–C4`), Vietnamese UTF-8 Token Estimator (`Measure-SenTokenEstimate`), `core`/`full` Edition Switch (`Set-SenEdition`), Memory Governance (`Add-SenExecutionLesson`), and Harness Capability Matrix (`CapabilityLevel`):** Saves 40–60% tokens on multi-file low-risk tasks and enforces lesson lifecycle metadata (`Stack`, `Confidence`, `Status`, `ExpiresAt`).
- **Mandatory Bilingual Release Notes Gate (`New-SenReleaseNote`, `Test-SenReleaseNoteGate`):** Automatically generates and enforces bilingual Vietnamese–English release notes per version (`docs/releases/vX.Y.Z.vi.md`, `vX.Y.Z.en.md`), cumulative master indexes (`RELEASE-NOTES.vi.md`, `RELEASE-NOTES.en.md`), and structured deferred item tracking (`.agents/office/deferred-items.json`).
